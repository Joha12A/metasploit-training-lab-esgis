# Fiches d'Analyse par Vulnérabilité

Ce répertoire regroupe les fiches d'analyse technique individuelles des dix vulnérabilités cibles de la VulnBox ESGIS (`10.1.0.1`).

Chaque fiche détaille :
1. **Contexte et identification** (Nom du service, port, version, référence CVE, score CVSS).
2. **Observations techniques** (Comportement du service, vecteur d'attaque, module Metasploit).
3. **Preuves réelles** (Emplacements réservés aux captures d'écran et sorties console effectives).
4. **Mesures correctives** (Plan de remédiation, patch et durcissement).
